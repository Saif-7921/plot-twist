# ✦ PlotTwist

A creative story playground built for the AWS Weekend Creative Challenge.

## What it does

PlotTwist turns a character, setting, genre, mood, and chaos level
into an unexpected short story with a plot twist.

## Features

- 🎲 Surprise Me
- 🔀 Remix the Twist
- 🎭 Multiple genres
- 🎨 Multiple moods
- 💥 Adjustable chaos
- 📋 Copy generated stories

## Architecture

React + Vite
        ↓
AWS Amplify
        ↓
AWS Lambda Function URL
        ↓
PlotTwist Creative Story Engine

## AWS Services

- AWS Amplify
- AWS Lambda
- Lambda Function URL
